# Africount Quick Start Guide

Get up and running with Africount in 15 minutes.

---

## 5-Minute Setup

### Step 1: Sign In (1 minute)
1. Go to https://africount-fzhxwte5.manus.space
2. Click "Sign in with Manus"
3. Enter your credentials
4. You're in!

### Step 2: Create Organization (2 minutes)
1. Click your profile icon (top right)
2. Click "Settings" → "Organization"
3. Enter your organization name
4. Upload a logo (optional)
5. Set timezone and currency
6. Click "Save"

### Step 3: Create Workspace (2 minutes)
1. Click "Create Workspace" on the dashboard
2. Enter workspace name (e.g., "Finance Department")
3. Select modules you need
4. Click "Create"
5. Invite team members (optional)

---

## First Actions

### Action 1: Record Your First Transaction (2 minutes)

1. Click "Transactions" in the sidebar
2. Click "New Transaction"
3. Select "Income" or "Expense"
4. Enter amount (e.g., 1000)
5. Select category (e.g., "Sales")
6. Enter date (today)
7. Click "Save"

**Result**: Your first transaction is recorded!

### Action 2: Create a Project (3 minutes)

1. Click "Projects" in the sidebar
2. Click "New Project"
3. Enter project name (e.g., "Website Redesign")
4. Enter budget (e.g., 5000)
5. Set start date (today)
6. Set end date (30 days from now)
7. Click "Create"

**Result**: Your first project is created!

### Action 3: View Analytics (2 minutes)

1. Click "Analytics" in the sidebar
2. Select date range (e.g., "Last 30 days")
3. View your metrics:
   - Total Revenue
   - Total Expenses
   - Net Profit/Loss
   - Cash Flow

**Result**: You can see your financial metrics!

## Common Tasks

### Task 1: Invite Team Members

1. Click "Settings" → "Team Members"
2. Click "Invite Member"
3. Enter email address
4. Select role:
   - **Admin**: Full access
   - **Manager**: Can edit data
   - **Agent**: Can enter data
5. Click "Send Invite"

### Task 2: Create a Budget Request

1. Click "Procurement" in the sidebar
2. Click "Submit Budget Request"
3. Select project
4. Click "Add Item"
5. Enter item name and price
6. Set quantity
7. Click "Submit for Approval"

### Task 3: Create a Balance Sheet

1. Click "Balance Sheets" in the sidebar
2. Click "New Balance Sheet"
3. Enter period (e.g., "Q1 2026")
4. Add assets:
   - Click "Add Asset"
   - Enter name and amount
5. Add liabilities:
   - Click "Add Liability"
   - Enter name and amount
6. Review equity (calculated automatically)
7. Click "Save"

### Task 4: Create a Custom Dashboard

1. Click "Custom Analytics" in the sidebar
2. Click "Create Dashboard"
3. Enter dashboard name
4. Click "Add Chart"
5. Select chart type (e.g., "Revenue vs Expenses")
6. Configure chart
7. Drag to position
8. Click "Save Layout"

### Task 5: Comment on a Chart

1. Click any chart in Custom Analytics
2. Click the "💬 Comments" button
3. Type your comment
4. To mention someone, type `@` and their name
5. Click "Post"
6. React with emoji (👍 ❤️ 😂 😮 😢 🔥)

## Common Questions

**Q: How do I reset my password?**
A: Click "Forgot Password" on login page.

**Q: Can I undo a deleted transaction?**
A: No, deleted items cannot be recovered. Review before deleting.

**Q: How do I export data?**
A: Click "Export" in any module and select format (CSV/Excel/PDF).

**Q: How do I import data?**
A: Click "Import Data" and select your file (CSV or Excel).

**Q: Can I have multiple workspaces?**
A: Yes! Create multiple workspaces for different teams or projects.

**Q: How do I change my role?**
A: Ask your workspace admin to update your role in Settings.
